# Licensing and asset provenance

## Original implementation

Unless a file states otherwise, original AR OS source code, QML, build scripts,
configuration, and programmatically created vector artwork in this repository
are intended to be distributed under **GPL-3.0-or-later**.

## Supplied concept references

`reference/Archive-original.zip` and `reference/original/IMG_*.jpg` came from the
user-supplied archive. The project owner states that AbdiRPC4789 gave permission
to use assets from AR OS / Miracle OS, create a real implementation, and use the
name AR OS. Those reference images are preserved for provenance and design work.
They are not automatically relicensed under the implementation's GPL terms.

Generated contact sheets and the catalog are analysis of those supplied files.

## Upstream software

Debian, Linux, Qt, KDE/KWin, Calamares, SDDM, NetworkManager, BlueZ, PipeWire,
systemd, Flatpak, PackageKit, and other packages retain their own upstream
licenses. This repository configures or links to them; it does not copy their
unrelated proprietary code or assets.
