# Changelog

## 0.1.0 — Developer preview

- Preserved and cataloged all 49 supplied AR OS 3 reference images.
- Established Debian 13, KWin Wayland, Qt 6/QML, SDDM, Calamares, and
  live-build architecture.
- Added AR Shell desktop, bar, dock, launcher, search providers, quick controls,
  notifications, and session integration.
- Added native Files, Settings, Software, Updater, About, OOBE, Lock, and Terminal
  experiences with real Linux service and filesystem boundaries.
- Added AR design tokens, vector wallpapers, logo, boot/login/installer themes,
  Debian packaging, ISO/QEMU scripts, CI, tests, security planning, and hardware
  documentation.
